# Whack-a-Mole Mandarin Game Sessions

Each session has a pre-game audio reader script and a matched target word/phrase bank.


## wm-01 — 天地人 + 金木水火土

**Source:** 识字1《天地人》, 识字2《金木水火土》


**Audio reader script:**

> 天地人。你我他。一二三四五，金木水火土。天地分上下，日月照今古。


**Game words / phrases:**

天地、你、我、他、一二三、四五、金木、水火、上下、日月、今古
